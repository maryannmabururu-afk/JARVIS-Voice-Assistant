# 🤖 JARVIS Voice Assistant
Built by Maryann | Python | Speech Recognition

An Iron Man style voice assistant that listens to voice commands and controls your laptop.

## ✨ Features
- 🎙️ Voice recognition
- 🎵 Play any song - "play diana hamilton" opens YouTube
- 🌐 Search - "google cybersecurity", "youtube search python"
- ⏰ Tells time
- 💻 Opens apps - Notepad, Calculator, VS Code, Gmail
- 🔌 Safe Shutdown/Restart with double confirmation
- 🗣️ Talks back with pyttsx3

## 🚀 How to Run
```bash
pip install pyttsx3 SpeechRecognition sounddevice
python jarvis.py
